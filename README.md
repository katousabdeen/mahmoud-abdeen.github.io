# Mahmoud Abdeen Portfolio

Professional one-page portfolio ready for GitHub Pages.

## Files
- index.html - Main page
- style.css - Styling
- script.js - Interactions
- assets/profile.jpg - Your photo
- assets/Mahmoud_Elsayed_Abdeen_CV.pdf - CV for download

## Deploy to GitHub Pages (Free)

1. Create new repo on GitHub named: `mahmoud-abdeen.github.io` (replace with your username) or any name like `portfolio`
2. Upload all files (drag & drop this folder content to repo)
3. Go to Repo > Settings > Pages
4. Source: Deploy from a branch, Branch: main, / (root)
5. Save. After 1-2 mins your link will be:
   https://YOURUSERNAME.github.io/
   or if repo is named `portfolio`:
   https://YOURUSERNAME.github.io/portfolio/

6. Put that link in your CV header next to LinkedIn!

## Customize
- Change colors in :root at top of style.css
- Update links in index.html
